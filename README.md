# AI TRADING BOT PRO 2.5 — Replit / Node.js

منصة تعليمية عربية للتحليل الفني والمحاكاة ومراجعة أخطاء التوقعات. لا يوجد اتصال بوسيط تداول ولا تنفيذ أوامر مالية.

## التشغيل
1. Node.js 20 أو أحدث.
2. `npm install`
3. عيّن `ADMIN_EMAIL` و`ADMIN_PASSWORD` (12 حرفًا على الأقل) و`JWT_SECRET` (32 حرفًا على الأقل) كمتغيرات بيئة آمنة.
4. `npm test`
5. `npm start`
6. افتح `http://localhost:3000`.

## الجديد في 2.5
شاشة «التطوير الذاتي» تسجل درجات التوقع والنتيجة الفعلية، وتصدر مراجعة يومية للأخطاء والاقتراحات. هذه دورة مراجعة يدوية التشغيل حاليًا، ولا تعدل الاستراتيجيات أو الكود تلقائيًا.

اقرأ `specification/START_HERE_AR.md` و`specification/MASTER_SPEC_AR.md` للتفاصيل وخطة الميزات الخمس عشرة.

## حدود النسخة
- تحليل قواعدي تعليمي، وليس نموذج ذكاء اصطناعي مدربًا.
- لا توجد بيانات سوق مباشرة أو تكاملات وسطاء.
- لا تنفيذ صفقات أو سحب أو تحويل أموال.
- ملف Android مصدر Android Studio وليس APK مبنيًا.
- تخزين JSON محلي مناسب للتجربة فقط؛ يلزم تخزين مُدار ونسخ احتياطي قبل نشر موثوق.

لا تضع كلمات مرور أو أسرار أو مفاتيح API داخل ملفات المشروع أو المستودعات العامة.
